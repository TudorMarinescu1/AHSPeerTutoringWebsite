# Agoura High School Peer Tutoring Website

This repository contains the public-facing website for Agoura High School Peer Tutoring. The site shares tutoring availability, announcements, and information for students who want academic support.

The project is currently a static website built with HTML and CSS.

## Project files

- `index.html` contains the page structure and content.
- `style.css` contains the site's visual styles and responsive layout.
- `assets/` contains the logo and website images.
- `CONTRIBUTING.md` explains the team's branch, pull request, and review process.

## Run the site locally

Clone the repository:

```sh
git clone https://github.com/TudorMarinescu1/AHSPeerTutoringWebsite.git
cd AHSPeerTutoringWebsite
```

Open `index.html` in a browser. You can also use a local web-server extension such as Live Server in VS Code.

## Team workflow

This is a small, trusted team working in a private repository. GitHub does not enforce branch protection on the current plan, so every collaborator agrees to follow these rules:

1. Never commit or push directly to `main`.
2. Create a new branch for each task.
3. Open a pull request for every change.
4. Have another team member review the pull request.
5. Address required changes before merging.
6. Let Tudor perform the final squash merge.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the complete workflow, a button-by-button guide to opening a pull request, and the reviewer checklist.

If this is your first contribution, start with [Step-by-step: open a pull request](CONTRIBUTING.md#step-by-step-open-a-pull-request).

## Privacy

Do not commit student records, private contact information, passwords, API keys, access tokens, or other confidential information. Ask Tudor before adding any content or image that identifies a student.
